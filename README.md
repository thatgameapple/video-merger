# Video Merge（VM）

> Purple Loop 配套小工具。把分段录制的视频拖进来即成「待合并清单」，按时段智能排序后无损拼成一个，方便后续做字幕识别和剪辑。

PyQt6 + FFmpeg。macOS（Apple Silicon）。

## 适用场景

录屏 / 摄像机 / 行车记录仪 类的设备常会把一段长视频切成 `00000.mp4`、`00001.mp4`、`00002.mp4`…… 一堆分段。在做字幕识别或丢进剪辑软件之前，先合成一整条会舒服很多。

VM 用 FFmpeg 的 concat demuxer（`-c copy`）直接拼，不重编码，几乎只受硬盘读写速度限制。

> 前提：所有分段是同一台设备同一次录制切出来的（编码 / 分辨率 / 帧率 / 时间基一致）。混合不同来源的视频请用别的工具——VM 会在合并前后各查一道，但查出来也只能提醒你，救不回来。

## 安装

从 [Releases](https://github.com/thatgameapple/video-merger/releases) 下载 `Video Merge_x.x_macos.dmg`，拖进 Applications。

FFmpeg 已内置，**无需额外安装任何东西**。

首次打开如果被 Gatekeeper 拦，去「系统设置 → 隐私与安全性」点「仍要打开」。

## 使用

把视频或文件夹**拖进窗口**即可——列表就是「待合并清单」，里面有什么就按顺序合并什么，不用再勾选。

1. 拖入视频 / 文件夹（或点「添加文件夹」）。拖文件夹会**递归**把里面（含子文件夹，如「某天/上午、下午、晚上」）的视频整批加进来；`._` 元数据文件已过滤。清单里显示的是相对拖入文件夹的路径，所以「上午/clip01」和「晚上/clip01」这种同名片段分得清
2. 清单按 **第几期 → 第几天 → 上午/下午/晚上** 智能排序（认中文数字）；排不准时**直接上下拖动行**手动调序
3. 拖错 / 多拖了点「撤销」去掉最近一批；想重来点「清空」
4. 确认「输出到」和输出文件名 → 点「开始合并」；合并时进度条按时长实时推进，按钮变成「取消合并」，随时可停（半成品会自动清掉）。合并期间清单会锁住不收新素材——这次合的是点按钮那一刻的清单
5. （可选）勾选「合并后删除原文件」，会有二次确认；有文件没删掉会如实告诉你是哪些。成片检查没通过时，删除确认里会先提醒你

**输出位置**：默认落在你拖进来的那个文件夹的**上一级**（跟它并排），文件名默认就是那个文件夹的名字——拖「第3天」进来，默认输出「第3天.mp4」到它旁边。这样成片不会混进素材堆、也不会被下次拖入扫成素材。想放别处点「更改」自己选，选过之后就不再被默认值顶掉。

### 三道防线

`-c copy` 的坑在于：**FFmpeg 返回「成功」不等于成片没问题**。所以查三次。

1. **合并前**比对各片段的编码 / 分辨率 / 像素格式 / **时间基** / **音频参数**，不一致弹窗列出差异让你决定。
   - 音频参数（采样率 / 声道）不一致：`-c copy` 照样报成功，但音轨比视频短，音画不同步
   - 时间基不一致（常见于换了机器录、帧率不同）：实测两段各 10 秒的素材能合出 24 秒的成片，音画从第二段起越错越多，而 FFmpeg 只吐 1 条警告。**这种能无损修**：弹窗里选「统一时基后合并」，VM 会先把少数派片段重封装成多数派的时基（`-c copy -video_track_timescale`，不重编码、画面数据逐字节不变），再拼。临时文件放输出文件夹（隐藏），合完自动删
   - 弹窗按参数分组列出文件名，片段少的那组排前面，混进来的是哪几个一眼看得到
   - 另外会先确认素材都还读得到：FFmpeg 碰到读不到的片段**不报错**（退出码仍是 0），会直接跳过后面所有内容合出一条短片子
2. **合并后**扫一遍 FFmpeg 的输出，时间戳异常 / 坏帧一类的警告如实报出来
3. **改名交付前**再用 ffprobe 复核一遍成片：总时长对不对得上素材之和、成片里视频轨和音轨是不是一样长。这一道最实在，前两道漏掉的都能兜住
   - **成片比素材短 = 直接判为合并失败**，不交付。这意味着有片段压根没合进去（坏片、外接盘中途断开），而 FFmpeg 对此不报错、退出码仍是 0。这种情况目标位置不会被改动、清单原样留着可以重合，也**绝不会走到「删除原文件」那一步**
   - 长了 / 音画不同步 = 内容都在但有毛病（且多半是你在事前弹窗里按了「仍要合并」），照常交付，只提醒

> 成片是先写成隐藏的临时文件、跑完再原子改名到目标位置的。所以合并失败 / 中途取消 / 关窗，都不会碰到已经存在的同名成片，也不会在素材目录里留残片。

合并成功后清单自动清空、准备下一批，**输出位置和文件名保留不动**（如「第3期第2天 左机位」只需手改成「右机位」即可接着合并）。**手改过的名字**永远保留；自动生成的名字（如拖「第2天」得到的「第2天.mp4」）会在你拖入新文件夹时跟着换成「第3天.mp4」，免得顺手覆盖掉上一条成片。点「清空」才会连输出设置一起重置。

支持格式：`.mp4` `.mov` `.mkv` `.avi` `.m4v` `.mts` `.m2ts`

## 从源码运行

```bash
brew install python@3.11
/opt/homebrew/bin/python3.11 -m pip install PyQt6

# 下载内置用的 ffmpeg/ffprobe 二进制到 bin/
./download_ffmpeg.sh

/opt/homebrew/bin/python3.11 merger.py
```

如果本机已装 ffmpeg（`brew install ffmpeg`），跳过 `download_ffmpeg.sh` 也能跑——程序会按以下顺序找：

1. `.app` 内置的二进制
2. 项目目录下 `bin/ffmpeg`
3. 系统 `PATH`（`shutil.which`）
4. `/opt/homebrew/bin/`、`/usr/local/bin/`

## 打包 DMG

```bash
./download_ffmpeg.sh
/opt/homebrew/bin/python3.11 -m PyInstaller merger.spec
# 然后用 create-dmg 出 dmg
```

## 配置

上次打开的文件夹、上次选过的输出位置记在 `~/.video_merger_config.json`。删掉这个文件即可重置。
